    P0 验收报告

    首轮验收结论留档

    范围：Cinder × Lucian UXUI 400 对标方案 P0 阶段的 12 个组件 + 10 个行为原语。 结论：构建 0 error，验收 126 项全通过（npm run build && npm run acceptance）。

    1. 交付清单

    1.1 样式（packages/base/src/components）

    组件 文件 承载的行为

    撤销条 undo-bar.css undo 原语（结构化消息 + 超时提交）

    1.2 行为原语（packages/base/src/primitives）

    status optimism undo stream gate gesture presence tempo focus durable

    原语与组件行为分层：原语只做正交能力（状态机、乐观提交、撤销队列、节流、焦点圈定、手势、进出场、持久化），组件行为负责 DOM 适配。打包顺序为先 primitives/ 再 behaviors/，组件内通过 C.Primitives 取用。

    1.3 构建规模

    base : 217 vars / 36 css / 10 primitives + 28 behaviors

    3. 本轮修掉的问题

    问题 根因 处理
    组合框过滤不生效 过滤走 120ms 防抖，断言在防抖前读取 验收补等待；同时修 Enter 未用方向键时 active=-1 取不到值 → 默认选首个可见项
    金额不补零 format 只截断不补齐 decimals>0 时 padEnd 补齐，1234.5 → 1,234.50
    金额非法标记取不到 data-invalid 挂在 .cin-currency 容器而非 input 验收改读容器；abc 类输入按「清洗为空」处理，不误报非法
    强口令被判弱 弱口令正则 ^(?:123|abc|...) 未闭合，Abc12345!xyz 被前缀命中 改为整串匹配，仅 abc123、password1 这类整体弱口令降档
    热力图回车无响应 只监听 click，未处理 Enter/Space keydown 内转发 click()
    下拉刷新失败抛全局错 catch 内 throw err，调用方未接则 unhandledrejection 只发 cin:refresh-failed 与 error 状态，不再抛出
    差异视图换行无效 按钮在 .cin-diff 之外，委托监听在 root 上收不到 演示页把按钮移入容器；组件侧维持 root 内委托的契约

    4. 取舍与遗留

    • 热力图与差异视图无独立行为脚本也能用：分档、换行由 CSS 属性驱动，脚本只补键盘与选中。二者已各带一个轻量行为，不额外增包。
    • 全量 102KB 超 30720B 参考线属预期：按入口考核，最重入口 7627B < 8192B，实际接入走 dist/entries/。
    • undo 条由原语动态挂到 #cin-undo-host，宿主需在页面预留该节点；未预留时原语降级为静默丢弃，不抛错。
    • 尚未覆盖：五档视口（320/375/768/1024/1440）截图回归、prefers-reduced-motion 下的进出场验证，留作 P1 验收项。
