    • 图标变形层（M1/M2）：新增 .cin-icon-stack 双层容器（外层尺寸恒定，只切 data-morph），M1 纯 CSS 交叉淡化零脚本可用；M2 Cinder.iconMorph 对同结构路径做归一化采样后逐帧插值，独立入口 dist/entries/base/icon-morph.js（5488 B / gzip 2542 B），单 rAF 共用、打断从中间态续、点数不匹配退回硬切、reduce 下不注册、时长只读 --cin-motion-base-duration。意图契约补双态变形与语义同步硬规则（形状变即 aria-label/aria-pressed 同步变），docs/agent-states.md 登记局部形态词 on/off。acceptance-icons.mjs 由 33 条扩到 62 条（含真浏览器：两档尺寸不跳、连点 20 次收敛、暗色不变形、reduce 不注册、无 JS 首态可用），demos/icons.html 新增「变形」区，README 新增 5.40。

    • 侧栏导航 sidenav（G6·T25）：components/sidenav.css + behaviors/sidenav.js + intents/sidenav.md + demos/sidenav.html。分组标题、导航项、当前项（底色 + 2px 内侧竖条双通道）、可展开子级（aria-expanded + aria-controls + hidden）、折叠图标栏（data-collapsed 联动 shell 侧栏 64/232 宽度）、窄屏抽屉（data-drawer，遮罩 / Esc / 焦点归还 / body 滚动锁 / 跨断点自动关闭）。键盘：↑↓ Home End 漫游（roving tabindex，展开时 ↓ 进子级、子级 ← 回父级且收起）、→ 展开、← 收起。无 JS 时子级全部展开可见、折叠按钮不出现，导航照常可点。

    • scripts/acceptance-sidenav.mjs：73 条断言——静态契约（入口 gzip ≤8KB、断点只用 tokens 的 900、无裸色值 / !important / 存储依赖、变量均有定义、intent 四节、i18n 双语言成对）＋ 宽屏实测（常驻宽度 232、当前项竖条、点击与方向键展开收起、roving 唯一 tabindex、closeAllSub / expand API、遮罩与 body 锁不残留）＋ 390px 抽屉实测（滑动可见、遮罩、焦点进入与归还、Tab 焦点环、无横向溢出）＋ 无 JS 与 reduced-motion 降级。

    • 在线 Playground：demos/playground.html——通用层令牌的实时调参台，零后端、零外链、零构建步骤，打开即用。可调品牌色（含 on-accent 亮度取反与 hover / pressed / soft / focus-ring 派生）、画布与表面色、圆角基准（xs/sm/md/lg 按比例派生）、阴影强度、正文字号（caption / label / display 联动）、字族、8 套皮肤与紧凑密度；改动即时写入 :root，右栏同步生成可直接覆盖的 CSS 片段，支持复制与下载 cinder-theme.css；状态序列化进 URL hash，链接可离线分享、刷新可还原。

    • scripts/acceptance-playground.mjs：32 条断言——静态契约（无外链、无后端依赖、导出区与三个操作入口齐备）＋浏览器实测（品牌色与派生令牌联动、圆角三级派生、字号联动、皮肤写入 data-skin、hash 往返还原、重置回落到库内默认、导出片段能被 CSSStyleSheet 解析），并设「页面引用的每个 --cin-* 必须在 dist/cinder-base.css 中真实存在」的防幻觉闸门——Playground 不可能凭空发明令牌。

    • demos/index.html 收录 Playground 入口。

    • scripts/audit-states.mjs：发布前四态巡检——按组件源文件（base 72 + erp 6，排除 .tokens.css）逐文件统计 hover / active / focus-visible / disabled 覆盖，--json 出机器可读结果。口径上只把「基座是否提供全局 :focus-visible」当硬项（base.css 已有全局轮廓，故退出码 0），hover / active 仅作观测：组件复用共享基类规则会被单文件统计误记为缺失，不据此判缺陷。

    • docs/release-audit-1.6.0.md：1.6.0 发布验收报告——门禁矩阵（build 0 error / 验收 68 组 / 视觉 63 页 / i18n 8-8 / 文档 23 文件）、80 个按需入口预算表（0 超标，最重 controls 8112 B 仅余 80 B）、四态观测与口径说明、4 项对外发布阻塞项及解锁条件。

    变更

    • 能力矩阵第 5 项「在线 Playground」由 ○ 升 ●，20 项基础设施计分 ● 15 / ◐ 2 / ○ 3（文档站落地后再补 1 项 ●），剩余 ○ 为 CDN、框架包装、Figma，已越过 ≥15 ● 合格线。
    • 视觉基线 50 → 51 页（新增 demos/playground.png），当前随新增组件扩至 56 页；acceptance-all 自动扫描收录 60 组验收脚本（scripts/acceptance-*.mjs 共 61 个，扣除总入口自身）。本轮只做口径回填，未重跑全量验收。

    说明

    • Playground 只读令牌、不生成新令牌：导出内容全部是库内既有变量名，颜色派生用 color-mix(in oklab, …) 就地表达，不预烘焙色阶。这样导出的片段永远跟库的令牌定义一致，不会出现「Playground 有、库里没有」的第二套真源。
    • 不做后端与保存：状态只存在 URL hash 里，不需要账号、不需要存储；这也意味着它可以直接扔进任何静态托管或随 demos/ 一起打开。
    • 与主题可视化生成器（第 6 项 ◐）的分工：Playground 负责「调参 + 导出 CSS」，生成式产出皮肤预设文件仍属第 6 项剩余工作。

    [1.6.0] - 2026-11-03

    新增

    • i18n 字典与取词原语：packages/base/src/primitives/i18n.js（9,676 B）内置 zh-CN / en 双字典（64 个 key），暴露 t / tIn / setLocale / register / apply / onLocaleChange / getLocale / locales / DICTS；支持 {name} 插值、data-i18n 与 data-i18n-aria 静态标记自动刷新、cin:localechange 事件、<html lang> 同步。
    • 21 个 behavior + 3 个原语接入取词：carousel、cascader、colorpicker、copy、datepicker、diffview、fileinput、format、otp、overlay、pullrefresh、pwstrength、qrcode、splitpanel、tags、timepicker、transfer、tree、virtualgrid，以及 primitives 的 stream / undo / status。原先散落的 aria-label、空态、按钮文字、相对时间全部改走 tr()。
    • scripts/check-i18n.mjs + npm run check:i18n：8 条一致性闸门（字典覆盖、双语 key 等价、占位符一致、兜底与字典逐字一致、无裸中文文案）。
    • scripts/acceptance-i18n.mjs：31 条断言，覆盖 lang=zh-CN / lang=en 两种首屏、运行时切换、register 扩展语言、以及"只加载分域包缺 core"的降级路径。
    • demos/i18n.html、docs/I18N.md。

    变更

    • 文案不再当选择器：timepicker 定位分钟列从 aria-label="分钟" 改为 data-col="minute"，翻译后仍能取到列。
    • 降级路径补齐插值：未加载 core 时 tr() 返回中文兜底并按同一套 {name} 语法就地替换，不会漏出占位符。
    • 能力矩阵第 11 项「i18n 字典」由 ○ 升 ●，20 项基础设施计分变为 ● 13 / ◐ 3 / ○ 4；视觉基线覆盖页 49 → 50（新增 demos/i18n.html）。
    • acceptance-all 收录组数 51 → 52；版本号 1.5.0 → 1.6.0。

    说明

    • 运行时切换不回溯已渲染组件：setLocale 刷新静态标记与后续取词，已生成的面板（如已展开的 timepicker 列名）需重新 init 或刷新页面生效。刻意不做组件级重渲染路径，避免每个组件维护两套渲染逻辑。
    • 纪律：新增任何用户可见文案，必须同时补 tr() 兜底与两套字典，兜底须与 zh-CN 字典逐字一致，否则 npm run check:i18n 直接失败。
