    v1.6.0 · 零依赖 · 不绑定项目

    一个能单文件拷走的通用 UI 组件库

    Cinder 由通用层（base）与按方向展开的定向定制层（当前 erp）组成。纯 CSS 负责形体，JS 只做渐进增强——删掉 JS，页面依然可读可操作。

    为什么不是又一套框架组件

    框架组件把样式和运行时绑死，你的页面因此必须长在那个框架里。Cinder 只提供两样东西：语义化的类名与可覆盖的令牌。它不认识你的技术栈，也不需要认识。

    三条硬约定

    • 零依赖：产物里没有第三方运行时，没有 CDN 请求，没有构建步骤也能用。
    • 可单文件拷贝：任何一个 dist/entries/** 入口都能单独拿走，已内联所需令牌。
    • 无中心注册表：不存在"必须先初始化一个全局实例"的前置条件。

    体积基线

    按入口考核，不按合订文件吓人：最重入口 entries/base/overlay.css = 7.6 KB（gzip，构建超 8 KB 直接失败）。全量合订 cinder-all.css + cinder.js 合计 169.7 KB——那是"全都要"的代价，正常接入不这么用。

    最短路径

    <link rel="stylesheet" href="dist/entries/base/base.css">
<button class="cin-btn" data-variant="primary">保存</button>

    要换皮就加 data-skin，要调令牌就去 Playground 拉一份覆盖片段，要接业务就只在定向层里加组件。
