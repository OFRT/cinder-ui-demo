    快速开始

    定位、安装、最小用法与目录约定

    零依赖、零框架的通用组件库，主体是 CSS + JS，不绑定任何具体项目。结构上分「通用层 + 定向定制层」：通用层（base）承载与业务无关的组件，定向定制层（erp 等）是在通用层之上按某个方向展开的定制，未来还会继续增加其它方向的定制层。 一份 tokens 真源、两层 @layer 隔离，两库可同时引入且互不串样式。

    1. 单入口已含全部 tokens + 重置（约 4.2 KB gzip 的固定底座），因此只引 1–2 个入口才划算；引 3 个以上直接上 cinder-base.css。

    三条硬约定：

    1. 只挂一个全局：域文件全部挂在 window.Cinder 下，不产生第二个全局变量；core 装原语，其余五域只装 behaviors，域内顺序与单体完全一致（拼接顺序 = behaviors/ 目录序）。
    2. core 是可选底座：behaviors 对原语是软依赖（形如 P().tempo ? 防抖 : 直调），不引 core 也能跑，只退化为无防抖、无状态色、无撤销栈等增强。
    3. 考核单位是"单页加载量"：任一单域 gzip 不得大于单体；把六个域全下载会比单体多约 5.7%（跨域重复的 IIFE / 选择器常量），那不是接入方式，只用于对照。

    dist/cinder-manifest.json 的 js.domains.files 给出每个域的文件路径、字节数、gzip 与所辖 behaviors 清单。

    3. 冲突是怎么被消掉的

    之前两份库各带一份 cinder.css，21 个同名类（.cin-btn / .cin-input / .cin-page …）实现不同，同时引入就会串样式。现在按「归属」拆干净：

    旧状态 现在
    .cin-btn 在 ui 用 --btn-bg 槽位，在 erp 用 --_h / --_px 只保留 base 一份实现，erp 不再定义
    .cin-page / .cin-panel / .cin-toolbar 两边各写一遍 归 base，erp 仅在业务父级下做微调（.cin-doc .cin-toolbar）
    137 个变量的取值在两边不一致 单一定义，erp 只追加 26 个新变量
    断点 3 档 vs 5 档混用 统一取 base 的 360 / 600 / 900 / 1200 / 1600

    构建期硬校验保证这四条不会退化：

    1. base 不得出现业务类（.cin-doc / .cin-pda / .cin-lines / .cin-print-* / .cin-beep …）与业务变量（--cin-erp-*、--cin-size-pda-* …）；
    2. erp 不得在顶层裸重定义 base 已有的类（媒体查询内做适配例外，如打印）；
    3. base 不得引用 erp 层变量（依赖方向反向即报错）；
    4. 所有 var(--cin-*) 必须有出处；断点只能来自 tokens；发现裸色值告警；花括号必须配平。

    node build.mjs --check 可单独跑，CI 用。

    体积预算

    按需入口是唯一考核对象：单个入口 gzip 后不超过 8KB，超出即构建报错（node build.mjs --check 退出码非 0）。理由是全量合订版只用于一次性预览，真实接入一律引 dist/entries/ 下的单个文件，一个页面通常只引一到两个入口。

    全量合订版不设阻断线，只在 report.json 的 budget.bundle 与构建日志里报数，超过 30KB 给一条 warning 供观察。当前基线：71 个入口中最重的是 base/overlay 7.5KB（7,628B / 8KB 的 93.1%），cinder-all.css 56.0KB 加 cinder.js 81.6KB，合计 140,880B（约 137.6KB）gzip。JS 分域同理按单域考核：任一域 gzip 不得大于单体，六域全下载比单体多约 5.4% 仅作观察。

    再往后加组件，只要单入口守得住 8KB，就不必为了全量体积砍功能。

    5.6 取色器 ColorPicker

    colorpicker.css 的底子仍然是原生控件：触发器里铺一个 input[type="color"]，没有脚本时点开的是系统取色盘，脚本跑起来才换成自绘面板。这样既不需要为一个取色器引入 canvas 拾色，也不会在弱环境里变成点不动的死按钮。

    结构 / 属性 说明

    .cin-colorpicker-trigger 触发器外壳，focus-within 出焦点环
    .cin-colorpicker-native 原生 input[type=color]，绝对定位铺满触发器；无脚本时点哪都能唤起。脚本接管后 pointer-events: none，但仍保留焦点与 aria-expanded
    .cin-colorpicker-chip 当前色块，背景读 --_c；data-alpha 时底下是棋盘格，透明色能看出来
    .cin-colorpicker-value 文本读数，与 data-value 同源
    .cin-colorpicker-pop 面板，position: fixed，由脚本夹进视口；--_h / --_s / --_v 三个局部变量驱动色域底色与拇指位置

    .cin-colorpicker-area-thumb 十字准星，位置由 --_s / --_v 算
    .cin-colorpicker-hue 色相条，原生 range 0-360
    .cin-colorpicker-alpha 透明度条，原生 range 0-100，仅 data-alpha 时出现
    .cin-colorpicker-field 数值框组：data-hex、data-r / data-g / data-b、data-a
    .cin-colorpicker-preset 预设色，色值写在 data-color，名字写 data-name（没有可见文本时当 aria-label）

    脚本只维护一份 HSV 状态，色域、色相条、透明度条、数值框、预设全读写它，因此不存在两个控件各记一份值的情况。拖动时写状态并抛 cin:colorinput，松手（或数值框回车、点预设、脚本赋值）才抛一次 cin:colorchange；cin:coloropen / cin:colorclose 跟面板开合同步。载荷统一为 { value, hex, rgb, hsl, alpha }，value 就是按 data-format 格式化后的字符串，也是写回容器的 data-value。

    几个约定：输出的十六进制统一小写，带 data-alpha 时给 8 位（#rrggbbaa），否则 6 位；hsl() 用现代空格写法 hsl(h s% l% / a)；非法输入（比如 #12 或不认识的字符串）在对应框上标 data-invalid，状态不动。弹层先试触发器下方，放不下翻到上方，再不行就 clamp 进视口；点外部、按 Esc、滚动与改窗口尺寸都会重排或关闭，Esc 之后焦点回到原生输入。编程赋值用 Cinder.setColorPicker(root, "#3E5A73")（也接受 rgb() / hsl() 字符串），返回格式化后的新值，非法值返回 null 且不改状态；动态插入调 Cinder.initColorPickers(root)。

    面板没有做 canvas 取色与吸管（EyeDropper），也不做渐变与多色停靠点：取色器的职责是选一个颜色，需要渐变停靠点的场景应当在画布层面另做控件。

    5.7 日期与时间 DatePicker / TimeInput

    日期框的底座同样是原生输入：文本框保留 input[type="text"] 手输 YYYY-MM-DD，日历面板由脚本注入。没有脚本时用户照样能把日期填进去并提交，只是拿不到日历；时间输入干脆不做自绘，直接用 input[type="time"]，CSS 只统一外观与焦点环。

    结构 / 属性 说明
    .cin-datepicker[data-datepicker] 容器；data-mode="single" / "range" 决定单选或区间，data-value / data-value2 写初值，data-size="sm" 收尺寸

    .cin-datepicker-pop 面板，position: fixed，由脚本夹进视口；打开时容器挂 data-open

  <div class="cin-datepicker-fields">
    <span class="cin-datepicker-field"><input data-date-field type="text" aria-label="账期开始"></span>

  </div>
</div>

    面板骨架（月/年下拉、42 格、今天/清除）由脚本按 data-label-* 生成，示例页不必抄三十行日历 DOM。范围模式下第一下定起始、移动指针出预览带、第二下收口，两框顺序颠倒会自动换位；Esc 与点外部都关面板，Esc 之后焦点回到第一个输入框。

    没做的部分：不做双月并排大日历、不做相对日期快捷项（「近 7 天」这类由业务层调 setDatePicker 实现），时区一律按本地时间处理，不做跨时区换算。

  <div class="cin-carousel-stage">
    <div class="cin-carousel-viewport">
      <ul class="cin-carousel-track">
        <li class="cin-carousel-slide"><img src="a.jpg" alt="工位全景"></li>
        <li class="cin-carousel-slide"><img src="b.jpg" alt="会议室"></li>
      </ul>
    </div>
    <button class="cin-carousel-nav" data-carousel-prev aria-label="上一张"></button>
    <button class="cin-carousel-nav" data-carousel-next aria-label="下一张"></button>
  </div>
  <div class="cin-carousel-footer">
    <div class="cin-carousel-dots"></div>
    <span class="cin-carousel-counter"></span>
  </div>
</div>
    结构 / 属性 说明
    .cin-carousel[data-carousel] 根容器，初始化后挂 data-carousel-ready；补 role="region"、aria-roledescription="轮播"，aria-label 缺省为「图片轮播」
    .cin-carousel-viewport 滚动视口，overflow-x:auto + scroll-snap-type:x mandatory，自动补 tabindex="0"；不产生横向滚动的容器无法初始化
    .cin-carousel-track 轨道，display:flex，间距跟随 --cin-space-*；无 JS 时直接拖动即可滑

    data-loop 循环：末页「下一张」绕回首张，两端按钮常亮不置灰
    data-autoplay="4000" 自动播放间隔（毫秒）。悬停、聚焦、按住拖动、页面切后台时挂起，移出或失焦后恢复；prefers-reduced-motion: reduce 下不启动，滚动改即时
    .cin-carousel-nav 左右按钮（data-carousel-prev / data-carousel-next），非循环态到端点自动 disabled，窄屏隐藏改手势滑动

    .cin-carousel-counter 页码「2 / 3」
    .cin-carousel-slide-body / .cin-carousel-caption 卡片式内容与单张说明文字

    没做的部分：不做无限克隆实现循环（靠页索引取模绕回）、不做缩略图条、不做多指缩放、不做纵向轮播；视频的播放与暂停交给业务层。

    5.10 虚拟滚动数据表 VirtualGrid

    万行级别的数据表不能整表入 DOM。data-virtual 把 tbody 变成固定窗口：只渲染视口内（加上下 overscan）的行，上下各放一个占位行把滚动高度撑到真实值，滚动时复用已有 <tr> 只改单元格内容。

    <div class="cin-dg" data-virtual data-height="520" data-row-height="44" data-overscan="8">
  <div class="cin-dg-scroll">
    <table>
      <thead>
        <tr>
          <th class="cin-dg-check"><input type="checkbox" data-check-all aria-label="全选"></th>
          <th data-key="code" data-sort="code" data-sticky>单号</th>
          <th data-key="item" data-sort="item">物料</th>
          <th data-key="qty" data-align="end" data-sort="qty">数量</th>
        </tr>
      </thead>
      <tbody><!-- 可留静态行作无 JS 兜底，初始化时被读成初始数据 --></tbody>
    </table>
  </div>
</div>
    结构 / 属性 说明
    .cin-dg[data-virtual] 根容器，初始化后挂 data-virtual-ready；必须同时具备 table 与 tbody，否则跳过
    .cin-dg-scroll 滚动容器，纵向 overflow:auto，高度由 data-height 或 --cin-dg-vheight 给，缺省 480px
    data-row-height 行长（px）。不给则用探针量 --cin-dg-row-h；量到的值会写回 --cin-dg-row-h，业务不必再算
    data-height 滚动视口高度（px），写入 --cin-dg-vheight
    data-overscan="8" 视口上下各多渲染的行数，快速滚动时的白色缓冲带；缺省 8
    th[data-sort] 可排序列，首点 ascending、再点 descending；data-key 缺省取列序号
    th[data-sticky] / td[data-sticky] 首列固定，横向滚动时贴在左侧
    .cin-dg-check + data-check / data-check-all 行选择与全选，表头自动半选态；全选作用于全部数据而非窗口内的几十行

    滚动高度的口径：表头（sticky thead）仍在文档流里占位，所以 scrollHeight = 表头高 + 总行数 × 行高。窗口起点按 scrollTop - 表头高 反算，scrollToIndex 的落点同样加表头高——三者口径必须一致，否则滚到底会差半个屏。

    行高必须严格等于声明值：占位行按 start × rowH 计算，只要真实行比声明值高几像素，滚到底就会差出几百像素。虚拟模式下因此把 .cin-check 的 44px 触控热区压回 min-height: 0，行内控件统一 vertical-align: middle 并限高 --_vrow-h - 8px。业务自定义单元格如果放了更高的控件（多行文本、头像、按钮组），要么改 data-row-height，要么在虚拟模式下裁掉。

    与 datagrid 的分工：同一个 .cin-dg 上，datagrid.js 只负责列优先级挤压（窄屏隐藏低优先级列），一旦带 data-virtual 就跳过选择与排序绑定，避免同一个 th 被两套逻辑各处理一次——否则一次点击会连翻两次方向，首点直接变降序。

    事件都从根节点冒泡：cin:virtualrange（{ start, end, total }）、cin:rowclick（行数据 + index）、cin:selection（{ count, indexes, values }）、cin:sort（{ key, dir, column }）。

    编程接口是 Cinder.virtualGrid(el) 返回的控制器：total / rowHeight / range / scroller 只读，setRows(list) 整表替换并回顶，appendRows(list) 追加且不跳位，updateRow(i, row) 就地改单行，scrollToIndex(i, { align }) 定位（start / center / end），select(indexes) / selected() / clearSelection() 管选择，refresh() 在行高或列结构变化后重测，destroy() 解绑。动态插入调 Cinder.initVirtualGrids(root)，重复调用安全。

    无 JS 兜底：脚本没跑时 data-virtual 不产生任何视觉变化，静态行照常可读，也不会多出占位行——验收里专门盯这条，避免"脚本挂了整张表空白"。

    没做的部分：不支持不定高行（多行文本需自己定高）、不做横向虚拟化（列数在几十以内）、不做分组折叠行、不做单元格编辑；十万行以上建议配 scrollToIndex 加分页，窗口渲染解决的是 DOM 数量，不是内存。

    5.12 格式化 / Markdown / 二维码

    格式化 Format 是四个纯函数加一个声明式渲染：

Cinder.formatDate("2026-11-01", { format: "iso" });             // "2026-11-01"
Cinder.relativeTime(Date.now() - 90_000, { locale: "zh-CN" });  // "1分钟前"

    非有限数字一律返回 "—"，不抛错、不返回 NaN——表格里用它最省事。formatBytes 默认 1000 进制，binary: true 按 1024 计算，单位标签统一写 KB / MB / GB；relativeTime 可用 base 指定参照时刻，便于测试和"截至某日"的展示。

    声明式渲染认 <time class="cin-time" datetime="…"> 或 [data-knowndate]：

    属性 说明
    datetime / data-time 时间源，ISO 字符串或时间戳
    data-format relative（缺省）/ absolute / both
    data-locale 语言，缺省跟页面
    data-abs-format both 模式下绝对时间那半边的格式，缺省 datetime

    渲染后写 textContent 与 title，注册进一个全局 ticker，每 60 秒重刷一次相对时间——不是每个节点各起一个定时器。

    Markdown。源文本放进容器即可，脚本整体转义后再解析，链接只放行 http(s) / mailto / tel / 相对地址：

    <div class="cin-markdown" data-markdown>
  ## 标题
  - 支持列表、**强调**、`代码`、表格
</div>

    也可以写 <script type="text/markdown"> 避开 HTML 转义。渲染完成的容器挂 data-markdown-ready，需要替换指定节点时给内部元素加 data-markdown-target。Cinder.renderMarkdown(src) 直接返回 HTML 字符串，.cin-markdown 样式负责排版。

    二维码 QR。内联 SVG，模块色走 currentColor，跟随文字颜色（含暗色模式），不需要图片资源：

    <div class="cin-qr" data-qr data-value="https://example.com" data-ecc="M" data-version="0" data-quiet="4" data-label="扫码打开"></div>
    属性 说明
    data-value 内容，缺省取元素文本
    data-ecc 纠错级 L / M（缺省）/ Q / H
    data-version 1-10，0 或不写按内容自动选最小可用版本
    data-quiet 静区模块数，缺省 4
    data-label SVG 的 aria-label，缺省用内容
    data-error-text 内容超出容量时的兜底文案，缺省"内容过长，无法生成"

    Cinder.encodeQR(text, options) 返回 { version, size, modules, ecc }，Cinder.renderQRCode(text, options) 直接给 SVG 字符串。版本上限 10，容量按 UTF-8 字节算（v10-L 约 271 字节，中文约 90 字），超出返回 null 或渲染兜底文案，不会画出错位的图。

    5.38 多语言 i18n

    组件产生的用户可见文案（空态、按钮、aria-label、相对时间）全部走一张字典取词，字典随 core 域分发：零依赖、无构建期编译、file:// 直开可用。原语在 packages/base/src/primitives/i18n.js，挂载点 Cinder.Primitives.i18n，内置 zh-CN（默认）与 en。

    <script src="dist/js/core.js"></script>
<script>
  const i18n = Cinder.Primitives.i18n;
  i18n.t("otp.digit", null, { n: 3 });   // 第 3 位验证码
  i18n.tIn("en", "copy.done");           // Copied（不改当前语言）
  i18n.setLocale("en");                  // → "en"，同时写 <html lang="en">
  i18n.register("ja", { "copy.done": "コピー済み" });
</script>
    成员 签名 说明
    t t(key, fallback?, vars?) 按当前语言取词；缺字典用 fallback，再缺返回 key
    tIn tIn(locale, key, fallback?, vars?) 按显式语言取词
    setLocale setLocale(tag, opt?) 归一化并切换，写 <html lang>，派发 cin:localechange
    getLocale getLocale() 当前生效语言
    register register(tag, dict) 注册或合并字典，后注册覆盖同名 key
    apply apply(scope?) 按 data-i18n / data-i18n-aria 刷新范围
    locales locales() 已注册语言列表
    onLocaleChange onLocaleChange(fn) 订阅切换，返回取消函数

    语言标签归一化：zh / zh-Hans-CN → zh-CN，en-US → en，未注册语言回落 zh-CN。

    不写 JS 也能吃多语言，元素内的原文即兜底：

    <p data-i18n="tree.noMatch">没有匹配的节点</p>
<button data-i18n-aria="copy.done" aria-label="已复制">复制</button>

    降级：只引分域包（无 core）时 tr() 回落中文兜底并照常按 {name} 插值；缺 key 依次回落 fallback → key 本身；新语言只翻一半时缺的回落 zh-CN。

    两条纪律：新增任何用户可见文案，必须同时补 tr() 兜底与两套字典（npm run check:i18n 第 4、5、7、8 条会拦）；setLocale 只刷新静态标记与后续取词，已渲染的面板需重新 init，不回溯重渲染。

    校验：npm run check:i18n（8 条一致性闸门）、node scripts/acceptance-i18n.mjs（31 条断言）、示例页 demos/i18n.html。完整约定见 docs/I18N.md。

    5.39 液态玻璃材质 glass

    玻璃是材质属性，不是组件：容器挂上 data-surface="glass" 就获得"背景被模糊、自身只淡淡着色"的浮起感，取掉属性立刻回到原样。所以没有 glass-card / glass-dialog 这类重复组件，浮层语义仍由 card、overlay、popover、toolbar、bulkbar、notice-bar、splitpanel 承担。

    <link rel="stylesheet" href="dist/entries/base/glass.css">
<div class="cin-card" data-surface="glass" data-tint="aurora">
  <p>面板内容</p>
</div>
    属性 取值 作用
    data-surface glass 开启材质；白名单容器：.cin-dialog-panel .cin-drawer-panel .cin-popover .cin-toolbar .cin-bulkbar .cin-notice-bar .cin-card .cin-splitpanel
    data-tint tide（缺省）aurora ember 三档色调，只换 --cin-glass-tint 与 --cin-glass-rim 两个量
    data-glass none 局部反选：回到实底、去模糊、去颗粒（父层玻璃不会渗进来）
    data-glass-enter 存在即生效 进场过渡走 --cin-motion-fast-*；reduce 下归零

    六个基础量（glass/glass.tokens.css）：--cin-glass-blur / -sat / -tint / -rim / -grain / -shadow，全部 --cin-glass-* 前缀，不覆盖任何既有令牌。暗色走 [data-theme="ink"] 与 prefers-color-scheme，高对比把 rim 换成正文色并把颗粒归零。

    四级降级（逐级都能用，不出现"全透明洞"）：

    级别 条件 表现
    L1 真玻璃 支持 backdrop-filter + color-mix 模糊 16px（≤600px 降 10px）+ 饱和 1.4 + 双层 rim
    L2 伪玻璃 不支持 backdrop-filter 半透明实色 + inset 高光，无模糊
    L3 无透明 prefers-reduced-transparency: reduce / forced-colors: active 退回不透明底色 + 1px 边框，颗粒关闭
    L4 无增强 整份入口不加载 容器就是普通卡片，页面不塌

    三条硬纪律：玻璃层内文字必须不透明（禁止 opacity 压字）；嵌套不超过 2 层；列表行 .cin-list-item、表格行 .cin-table tr、网格项 .cin-grid-item、表单控件永久不挂玻璃（滚动时逐行重算模糊会直接吃帧率）。

    吸附条 .cin-glass-dock 静态靠 scroll-snap 就能用，Cinder.glassDock.initAll() 只是可选增强（滚轮转横向、方向键切换并居中），不加载时静态完全可用；prefers-reduced-motion 下取消平滑滚动。

    校验：node scripts/acceptance-glass.mjs（36 条断言：令牌齐备、降级块存在、backdrop-filter 只在玻璃选择器上、反选无模糊残留、玻璃上文字不透明、强制色关闭模糊）、示例页 demos/glass.html（含容器矩阵、三档 tint、四级降级对照、玻璃套玻璃反例）。方案与取舍见 docs/liquid-glass-plan.md。

    5.40 图标变形 icon morph

    一个图标位要表达两种形态（播放 ↔ 暂停、展开 ↔ 收起、方形 ↔ 三角），最常见做法是切 class 或换 src——结果是外框尺寸跳、布局抖、过渡要么没有要么很贵。层里给两档：

    档 依赖 做法 代价
    M1 交叉淡化 纯 CSS，零脚本 两层图标同格叠放，切 data-morph 只改 opacity + 轻微 scale/rotate 0 KB JS；两形状不同时中间态是"叠影"而非"变形"
    M2 真插值 dist/entries/base/icon-morph.js（gzip 2.5 KB） 取两条路径归一化采样点，逐帧插值 d 只对同为路径的图标对成立；点数不同直接退回硬切 
    <span class="cin-icon-stack" data-morph="on" data-size="lg">
  <svg data-state="on" viewBox="0 0 24 24" aria-hidden="true"><path d="M8 5h8v14H8z"/></svg>
  <svg data-state="off" viewBox="0 0 24 24" aria-hidden="true"><path d="M12 3l9 18H3z"/></svg>
</span>

    外框尺寸由 .cin-icon-stack 决定（--cin-size-icon-md 20px / [data-size="lg"] 24px），两层绝对定位不参与撑高，所以切换前后元素盒子一模一样，不会推动同行按钮。

    M2 的四条实现纪律：① 全局只跑一个 rAF 循环，多个图标同帧推进；② 打断时从当前中间态续跑，不从起点重来（连点不闪回）；③ 采样点数不一致就跳过插值直接切层，不硬凑；④ 时长只读 --cin-motion-base-duration，不写裸 ms，prefers-reduced-motion 下根本不注册动画。

    语义必须同步：形状变了，aria-label 与 aria-pressed 必须一起变——只切图形不改语义，屏读会继续念旧状态。这一条是硬规则，写进 packages/base/src/intents/icons.md。

    降级：无 JS 时 M1 静态照常（CSS 管两态）；forced-colors 下直接 display: none 切层，不做透明度动画；prefers-reduced-motion: reduce 下 transition: none。

    校验：node scripts/acceptance-icons.mjs（62 条断言，含真浏览器实测——24/32 两档切换尺寸不变、连点 20 次收敛且语义同步、暗色不变形、reduce 下不注册动画、禁用 JS 后首态可见且次态不占位）。示例页 demos/icons.html「变形」区。

    8. 设计红线（成文规则）

    混用体系必须有成文规则，新增组件按本节取值，不再逐页临时决定。

    形状分级

    层级 圆角 适用
    控件 --cin-radius-sm（8） 按钮、输入、选择、分段、标签
    容器 --cin-radius-md（12） 卡片、面板、弹窗
    大浮层 --cin-radius-lg（20） 抽屉、全屏浮层、大区块容器
    胶囊 / 圆形 --cin-radius-full 头像、状态点、引导圆点
    无圆角 硬编码 0 仅表头与页签底板，其余位置禁止

    颜色

    • 禁用纯黑纯白：卡片面用暖白（#FEFDFB / #FFFDF8），浅色主题反白字 #FDFBF7，暗色主题反白字 #141210。
    • 强调色每套皮肤只有一个，饱和度 ≤ 76%，明度保持品牌观感；accent.default 对画布 ≥ 4.5（现值 4.76），text-on-accent 对强调色 ≥ 4.5。
    • 状态色不改语义，只用色相区分：成功绿、警告琥珀、危险红、信息蓝。

    边界与对比度

    • border-strong 承担控件边界语义（输入框、选择器、次级按钮、步进器）：对 bg-surface 与 bg-surface-sunken 均 ≥ 3:1（WCAG 1.4.11），构建期硬校验。
    • border-subtle 仅装饰，不承担边界语义：只用于表格分行、区块分隔，禁止用于输入框或可点击控件的外框。

    暗色与系统偏好

    • 未设置 data-theme 时，@media (prefers-color-scheme: dark) 自动映射到 ink；显式 data-theme 优先级更高，data-skin 在其之上覆盖颜色。
    • 滚动与定位：组件不注册高频 scroll 处理；Tour 采用 rAF 合帧 + ResizeObserver，位移只写 transform，滚动监听仅作 passive 兜底。
    • 文案：禁用破折号字符，一行最多一个中圆点。

    9. 已知边界

    • 只做样式与少量 DOM 行为，不含业务逻辑；表格排序、筛选由页面自己接。
    • 数据表自适应依赖容器查询，容器必须是 .cin-dg-wrap，且引用方浏览器需支持 container-type（Chrome 105+ / Safari 16+）。
    • cinder-erp.css 不能单独引，缺 base 会丢失全部基础语义与变量。
    • 弹窗依赖原生 <dialog> 与 ::backdrop（Chrome 37+ / Safari 15.4+）；引导 Tour 需要目标元素可见，目标隐藏时自动跳过该步。
