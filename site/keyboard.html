    键盘矩阵

    每个组件的键位契约与实测档位

    汇总自 73 份意图契约（packages/base/src/intents/*.md）第三段"可访问性"，由 scripts/gen-keyboard-matrix.mjs 自动生成，与源码同源；禁止手改，改契约后重跑脚本。 用途：基础设施 #17「键盘操作全覆盖」的文档面。

    三档说明：

    • A 有完整键位契约：组件自行接管键盘事件，键位在契约中逐项写明；行为实现在 src/behaviors/<name>.js。
    • B 有行为层但未单列键位：src/behaviors/ 内无键盘接管（或仅有 Esc / 焦点管理），交互靠鼠标与原生事件；需要键盘操作时按原生元素规则走。
    • C 纯样式组件：只有 CSS，无 JS；语义与键盘能力完全由所用 HTML 元素决定（button / input / a 天然可达，div 不会因为套了 Cinder 类名就变可达）。

    A · 有完整键位契约（41）

    组件 键位（摘自意图契约）
    calendar 键盘：整月 Tab 站点太多时，用 roving tabindex（一格 tabindex="0"，其余 -1）由脚本管理；calendar 不做漫游逻辑。
    carousel 键盘（视口聚焦后）：← / ↑ 上一页，→ / ↓ 下一页，Home 首张，End 末页，并阻止页面滚动。
    cascader 键盘：↑/↓ 列内移动，←/→ 换列，Enter 落定当前项，Esc 关闭并把焦点还回输入框。
    colorpicker 色相条与透明度条用 role="slider" + aria-valuenow/min/max + aria-label（"色相"/"不透明度"），支持 ← / → 微调、Home / End 到端点。
    combobox 键盘：↓/↑ 移动高亮并循环、Enter 选中、Esc 收起并归还焦点到输入框、Tab 离开即收起。
    command-palette 键盘：↑/↓ 移动、Enter 执行、Esc 关闭并把焦点还给唤出前的元素。
    context-card 来源用真实链接：<a href> 自带键盘可达与读屏语义；外链不要用 target="_blank" 时缺 rel="noopener"。
    controls 键盘：所有控件走 Tab 序；.cin-segment 用 radio 组语义（组内方向键切换），.cin-switch 用 role="switch" 或原生 checkbox。
    copytarget 键盘：Enter / Space 触发，焦点环保持；成功后不移动焦点。
    currency-input 使用 inputmode="decimal"，移动端唤起数字键盘；type 保持 text 以免格式化字符被浏览器丢弃。
    datepicker 键盘按原生日历约定：← / → 一天，↑ / ↓ 一周，Home / End 本周首尾，PageUp / PageDown 翻月（加 Shift 翻年），Enter 落定，Alt+↓ 唤起面板。
    diff-view 横向滚动区必须可键盘聚焦（tabindex="0"）并带 aria-label，否则键盘用户无法横向查看长行。
    disclosure 键盘：Enter / Space 翻转当前项；↑ / ↓ 在组内项间移动焦点；Home / End 跳首末；data-disabled 项跳过。
    entity 悬停才有 .cin-entity-actions（如出现「发消息」按钮）时，动作必须也能被键盘 Tab 到，不能只在 :hover 里 display: none 隐藏。
    fileinput 触发器必须是 <label> 关联真实 input[type="file"]（cin-sr-only 隐藏），键盘 Enter / Space 可唤起系统选择框。
    heatmap 逐格 Tab 会制造上百个焦点停靠点，应使用单焦点 + 方向键在网格内移动（roving tabindex）。
    inline-edit 键盘：Enter 进入编辑、编辑内 Enter 提交、Esc 取消、Tab 从输入框到确认/取消。
    input-number 输入框是原生 <input type="number">，inputmode 按整数/小数分别给 numeric / decimal；上下方向键与原生行为一致。
    lightbox 键盘：←/→ 切换、Esc 关闭、Tab 在关闭/导航按钮间循环（焦点陷阱），关闭后焦点回到触发缩略图。
    list data-hoverable 的焦点反馈走 :focus-within / :focus-visible，键盘 Tab 能看见当前位置。
    morph-button 根节点用原生 <button type="button">；loading 设 aria-busy="true" 并保持可聚焦，键盘用户仍能感知状态变化。
    option-group 键盘：原生 checkbox / radio 的方向键与空格行为保持可用，不要加 tabindex="-1"。
    otp inputmode="numeric" + autocomplete="one-time-code"（首格）以支持短信验证码自动填充与移动端数字键盘。
    overlay 键盘：Esc 关闭（data-static 除外）、Tab 在面板内循环、关闭按钮是首个可聚焦项、关闭后焦点回原触发器。
    popover 键盘：零脚本模式下 Tab 进入触发器即展开，Tab 可进入面板内部；面板内第一个可聚焦元素不要抢焦点（非模态，不锁焦点）。
    prompt-bar 键盘：Enter 提交（菜单打开时选中当前项）、Shift+Enter 换行、↑/↓ 移动选项、Esc 收起菜单、Tab 收起菜单并离开；e.isComposing 为真时一律不拦截，避免中文/日文输入法确认候选被误提交。
    rating 键盘：← / → 在星间移动并即时选中（原生 radio 行为），Tab 只进整组一次；DOM 顺序与视觉顺序一致，不得用 flex-direction: row-reverse 反转（会反转方向键）。
    result 操作区按钮使用 controls 的 .cin-btn，焦点环与键盘可达性由它保证。
    scroll-area 滚动容器要被键盘操作，需 tabindex="0"；同时给 role="region" 与 aria-label（如「最近的报销单」），否则读屏用户不知道这块可滚。
    segmented 键盘操作遵循单选组惯例（方向键移动即选中），不额外发明快捷键。
    selection-actions Tab 进入动作条 → ←/→ 在动作间移动 → Enter 或空格 触发当前动作 → Esc 关闭（不改选区、不移动焦点）。
    sidenav 顶层 ↑ ↓ 首尾回绕，Home / End 跳两端，→ 展开子级、← 收起；子级项 ↑ ↓ 在可见项间顺排，← 回父级并收起；Esc 关闭抽屉；抽屉打开时 Tab 不越出抽屉。
    slider ← / → 单步，PageUp / PageDown 大跳，Home / End 到两端，data-format 后的读数通过 aria-valuetext 播报（如"¥4,000"），不要只让读屏念数字。
    splitpanel 键盘：← / → 微调（纵向用 ↑ / ↓），步长 data-step，Shift ×5；Home / End 到上下限；双击复位只服务鼠标，键盘用 Home 回中间或宿主提供按钮。
    table 表头加 aria-sort="ascending／descending／none" 与可点击按钮；排序列的 th 内不要直接绑 onclick 到文字上（键盘进不去）。
    tabs 横向 ← / →，纵向 ↑ / ↓，均首尾回绕；Home / End 跳两端；Enter / Space 在手动激活模式下提交；Tab 从当前 tab 直接进入面板内容。
    tag-input 键盘：输入框内 Enter 提交当前输入、Backspace 在空输入时删除最后一个标签、←/→ 可在标签间移动焦点。
    timepicker 键盘：↑/↓ 列内移动，←/→ 换列，Enter 落定，Esc 关闭并把焦点还回输入框。
    tree 键盘：↑ / ↓ 在可见项间移动、→ 展开或进入首子项、← 收起或上到父项、Home / End 跳首末、Enter 选中；data-select="multiple" 时 Space 勾选。
    undo-bar 撤销必须同时可由键盘触发（按钮为原生 button），Esc 关闭视为放弃撤销。
    virtualgrid 键盘滚动：视口需 tabindex="0" 以便用方向键/PageDown 滚动；不要依赖鼠标滚轮作为唯一路径。

    通用键位约定（所有组件共有）

    键 约定
    Tab / Shift+Tab 焦点顺序跟随 DOM；复合控件内部用 roving tabindex 或 aria-activedescendant，整体只占一个 Tab 位
    Esc 关闭当前浮层（dialog / popover / command-palette / cascader），关闭后焦点回到触发元素
    Enter / Space 激活当前项的默认动作；在 button 上二者等价
    Home / End 列表、页签、树、网格跳首/尾
    方向键 平行结构内漫游（首尾回绕，跳过禁用项）；data-orientation="vertical" 时只响应上下
    焦点可见 统一 :focus-visible（鼠标点击不显示焦点环），颜色走 --cin-color-focus-ring 令牌

    维护规则

    • 新增 A 档组件：在 intents/<name>.md 第三段写明"键位："，然后重跑 node scripts/gen-keyboard-matrix.mjs。
    • 删除或下移组件：重跑脚本即可，禁止手改本表。
