轻提示 Toast

2.4s 自动消失

不遮挡操作区、不抢焦点；悬停即暂停倒计时。语气色只有 success / danger / info 三档。

气泡提示 Tooltip

四向 · 280px 上限
按最近一次同步时间排序 导出当前筛选结果 含税价，单位：元 需要「库存管理」权限

只解释图标或字段含义，不放操作；键盘 focus 同样触发，Esc 关闭。

气泡确认 Popconfirm

行内二次确认
删除这行明细？ 删除后需重新录入，单据合计会自动重算。 标记为已对账？ 标记后将锁定本期金额。

抽屉面板 Drawer

保留原页面

320 / 420 / 560 三档，移动端自动全宽；抽屉内可滚动，页脚固定。

模态窗口 Modal

聚焦单一任务

Esc / 点遮罩可关；焦点锁在面板内，关闭后回到触发按钮。

警告框 Alert Dialog

不可逆操作

必须明确选择才可关闭，默认聚焦「取消」，语气色随风险等级。
