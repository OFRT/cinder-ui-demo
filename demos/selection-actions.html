Cinder Base selection-actions 选中文本浮出动作条；无 JS 时整条不出现

基础：选中正文 → 解释 / 改写 / 翻译 / 追问

用鼠标拖选下面任意一段文字，动作条贴着选区上方浮出；上方空间不足时自动翻到下方。

分层样式表的顺序决定覆盖结果。基础层只放通用结构与状态，业务层只放业务结构性尺寸；两库靠 cascade layer 顺序共存，同名类归基础层单一定义。

把「选中即问」做成独立组件而不是编辑器的一部分，是为了让阅读态的正文、表格、代码块共用同一套动作契约，也避免富文本编辑器把选区逻辑带进只读页面。

事件日志：等待选中文本

状态：处理中 / 失败带原因 / 复位

动作触发后由宿主决定终态；失败必须给文字原因，不能只改边框。

先选中一段文字让动作条出现，再点上面的按钮观察。

窄屏：≤30rem 动作换行不溢出

把窗口宽度缩到 480px 以下（或手机打开本页），选中这段文字：动作条贴边、按钮换行、关闭键回到行尾，不会横向溢出。

无 JS：组件不出现

删除 dist/cinder.js 后，下面的标记仍在 DOM 里，但 CSS 基础态是 display:none，页面不会留下空壳或残影。

<div class="cin-selactions" data-selactions>
  <div class="cin-selactions-panel">…</div>
</div>

无脚本时正文照常可选中、可复制，只是不提供动作条。
